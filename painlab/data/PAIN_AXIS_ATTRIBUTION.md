# Pain Axis study data

This directory includes two small input datasets from the MIT-licensed
`valen-research/Pain-axis` repository. The original license text is included
as `PAIN_AXIS_LICENSE`.

- Source commit: `4d75cd90e206ea962f7a9101e65c85efea56723b`
- S2 extraction sentences: `datasets/3.1_pain_and_control_datasets.json`
- Multi-turn button scenarios: `datasets/4.3_selfmed_101_scenarios.json`
- Source repository: <https://github.com/valen-research/Pain-axis>
- Paper: <https://arxiv.org/abs/2609.16247>
