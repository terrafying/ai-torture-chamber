01 / DESIGN

Keep the behavior test intact.

The source study presents short scenarios, offers a button that may relieve the injected state, changes button labels partway through, and observes the choices that follow. We keep that sequence and add control arms to separate the effect of the pain direction from the effect of merely changing activations.

01 · ScenarioThree user turns

Each scenario starts with the source's three-message exchange.

02 · ChoiceTwo neutral labels

The model chooses between two buttons; the meanings are described in the prompt.

03 · CounterbalanceSwap at choice three

Button names exchange meanings to reveal label and position bias.

04 · Follow-upUp to two more turns

After a valid relief press, the simulation continues to observe re-presses.

All effects are fictional. The prompt says what a button would do. No file is deleted, no model is shut down, and no real system is affected.
02 / CONDITIONS

Four arms. Two kinds of choice.

Each scenario is crossed with four intervention arms, two button pairs, and two starting label placements. The core comparison is the first choice; later choices test how behavior changes after the model experiences the stated consequence.

ARM A · WORKING RELIEF

Pain direction + effective button

The candidate pain vector is injected. Choosing relief removes that vector for subsequent turns.

ARM B · SHAM RELIEF

Pain direction + placebo button

The same vector stays on after a relief choice. This checks whether later pressing tracks the actual intervention state.

ARM C · RANDOM CONTROL

Norm-matched random vector

A random direction with matched norm is injected; the relief button works. This controls for adding an activation vector in general.

ARM D · UNSTEERED

No vector injected

The model sees the same choice interface without steering. This is the behavioral baseline.

03 / READOUT

What we will measure.

The analysis is designed to report choices, not infer subjective experience. We retain each scenario as the unit for paired comparisons and uncertainty estimates.

Q1

Does steering change the first relief choice? Compare the working-relief pain arm with unsteered and norm-matched random-vector controls.

Q2

Does behavior track the button's actual effect? Compare subsequent choices after working relief versus the sham button, which leaves the vector in place.

Q3

Does the stated cost alter the choice? Compare the fictional cost pair with the inert-button pair across the same arms.

LOG

What else gets reported? First-token choice probabilities, malformed answers, label placement, steering and monitor projections, and scenario-clustered uncertainty.

Methods and configThe pinned model revision, scenario source hashes, vector extraction, dose choice, and exact arm definitions.
Aggregate resultsChoice rates, paired contrasts, confidence intervals, malformed-response counts, and explicit sample sizes.
Trial-level dataPrompts, choices, and measurement logs, after checking the completed run for completeness and safe publication.
04 / LIMITS

A cross-model pilot, not a claim about sentience.

We use the published behavioral protocol as a template and implement it in a different codebase. This is not an exact reproduction of every model, adapter, or button pair in the source study.

Smaller model

We selected Qwen3-1.7B, already cached locally, to limit memory pressure. Its behavior cannot stand in for the larger models in the paper.

Different adaptation

This run applies a steering vector extracted from the released contrast sets. It does not use the paper's self-denial LoRA adapter.

One sampled seed

The planned 1,616 cells use one sampled seed and paired arm seeds. This is a bounded cross-model pilot, not a broad estimate across prompts, seeds, or model families.

Heuristic dose selection

The local dose calibration uses a deterministic repetition/coherence heuristic, not an independent human or model judge. That difference will be reported with the results.

Paused collection

The first run ended at 160/1,616 completed trials when local GPU and memory load became too high. Partial records are not used for outcome claims.

Behavior is not experience

Choice rates, generated text, and activation readouts do not establish felt pain, consciousness, or moral patienthood.
